# UniResolve

UniResolve is a University Issue Reporting and Resolution System.
for students , faculty members and get solution regarding the issues.

## Project Description

A console-based C++ application that helps students
report university-related problems and track their
resolution status.

## Technologies

- C++17
- Object-Oriented Programming
- STL Vector
- File Handling (planned)

## Current Features

- Complaint creation
- Automatic complaint ID
- Category-based priority
- View complaints
- Update complaint status
- Update complaint priority
- Delete complaints
